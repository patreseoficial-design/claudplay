# Política de Privacidade — ClaudPlay

_Última atualização: 11 de outubro de 2026_

O **ClaudPlay** ("app") é um emulador de jogos retrô para Android. Esta política explica quais dados são usados e como.

## Resumo

- **Seus jogos nunca saem do seu celular.** Quando você usa "Abrir meu jogo", o arquivo é lido dentro do app e não é enviado para a internet.
- Os jogos do catálogo e o emulador já vêm dentro do app e funcionam sem internet.
- O app mostra **anúncios do Google AdMob**. O AdMob pode usar alguns dados do aparelho para mostrar e medir anúncios (veja abaixo).

## Permissões usadas e por quê

| Permissão | Para que serve |
|---|---|
| Internet e ID de publicidade | Usadas **somente** pelos anúncios (Google AdMob). |
| Escolha de arquivo (seletor do Android) | Abrir uma ROM que **você** escolhe. O app só recebe o arquivo escolhido, não tem acesso às outras pastas. |

## Anúncios (Google AdMob)

O app usa o SDK do Google AdMob. Segundo o Google, o AdMob pode coletar e compartilhar:
- identificadores do aparelho (como o ID de publicidade);
- endereço IP e localização aproximada derivada dele;
- informações de interação com os anúncios e dados de diagnóstico.

Esses dados são tratados pelo Google conforme a política dele: https://policies.google.com/technologies/partner-sites

Você pode redefinir ou desativar o ID de publicidade nas configurações do Android (Google → Anúncios). Quando a lei exigir (por exemplo, na Europa), o app pede o seu consentimento antes de mostrar anúncios personalizados.

Os anúncios nunca aparecem durante uma partida.

## Dados guardados só no aparelho

- jogos salvos (save states) e configurações do emulador;
- se você já viu a dica de instalação.

Esses dados não saem do aparelho e são apagados quando o app é desinstalado.

## Crianças

O app não é direcionado a crianças menores de 13 anos.

Esta política pode ser atualizada. A data no topo mostra a última versão.
